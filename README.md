# Centrala 2 — Ustawienia i baza pracowników

Ten projekt należy wkleić do osobnego Arkusza Google. Po instalacji uruchom:

1. `dbInstall`
2. `dbLoadDemo`
3. `dbValidate`

Identyfikator utworzonego Arkusza wklej w pliku Planner do arkusza `CENTRALE`, przy kluczu `USTAWIENIA_FILE_ID`.

W produkcji dane demonstracyjne w `BAZA_PRACOWNIKÓW` zastępuje się danymi pracodawcy. Nazw kolumn nie wolno zmieniać.
